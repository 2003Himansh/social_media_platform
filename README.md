# Django Social Media Platform

A complete social media platform built using Django. Users can create profiles, share posts, like, comment, and connect with friends.

##  Features

- User Authentication
- User Profile System
- Create and Share Posts
- Like and Comment System
- Friend Request System
- Notifications
- REST API
- Responsive UI

##  Technologies Used

- Python
- Django
- Django REST Framework
- Bootstrap
- SQLite

## Installation

Clone the repository

git clone https://github.com/yourusername/django-social-media-platform.git

Move into project folder

cd django-social-media-platform

Install dependencies

pip install -r requirements.txt

Run migrations

python manage.py migrate

Create admin user

python manage.py createsuperuser

Run the server

python manage.py runserver

Open browser

http://127.0.0.1:8000

## Project Modules

- Users (Profile system)
- Posts (Create posts and images)
- Friends (Follow and friend requests)
- Notifications
- REST API
